## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Sensory Overload**. This trainer provides configurable practice and accessibility controls for Sensory Overload. It is designed around the game's precision movement, obstacle avoidance, timed runs, escalating speed, and Normal, Ranked, and Zen modes.

**Target Audience:** Players who want to practice difficult stages, learn obstacle patterns, reduce the intensity of visual effects, or explore Sensory Overload outside standard challenge conditions.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Invulnerability** — Prevents crashes from ending the current run, allowing uninterrupted practice through difficult stages.
- **Slow Motion** — Reduces game speed to make fast obstacle patterns and dense sections easier to study.

- **Freeze Run Timer** — Pauses the active run timer while the player studies tunnel layouts and obstacle timing.
- **Obstacle Visibility Assist** — Improves obstacle visibility during practice by reducing the impact of intense visual effects.
- **Practice Mode** — Combines training controls for learning stages, testing movement techniques, and reaching difficult sections safely.

## 📖 Detailed Feature Guide

### Movement & Exploration

Sensory Overload is built around first-person descent and precision steering. Use Slow Motion and Movement Speed Control to learn how the player moves through narrow passages, rotating sections, dense obstacle fields, and rapidly escalating stages. Invulnerability is useful for identifying safe routes without restarting after every collision.

### Tools & Inventory

Sensory Overload has no traditional inventory, equipment, weapons, or collectible item system. Trainer options focus on movement, run conditions, visibility, and practice controls instead.

### World & Environment

The game consists of seven levels and 64 stages featuring twisting tunnels, psychedelic patterns, breathing walls, shifting colors, and escalating visual chaos. Normal Mode focuses on survival and scoring, Ranked Mode increases the challenge through endless escalation, and Zen Mode provides an indestructible experience centered on the tunnel.

### Combat & Weapons

There is no combat system in Sensory Overload. Progress depends on steering, timing, obstacle avoidance, controlled movement, and surviving each descent.
